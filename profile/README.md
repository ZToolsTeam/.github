<h1 align="center">ZTools</h1>

<p align="center"><strong>按一下，就到。</strong></p>

<p align="center">面向 Windows 与 macOS 的桌面效率启动器与插件中枢。</p>

<p align="center">
  <a href="https://www.ztools.cn">官网</a> ·
  <a href="https://www.ztools.cn/download.html">下载</a> ·
  <a href="https://github.com/ZToolsTeam/ZTools/issues">问题反馈</a>
</p>

通过快捷键打开工作台或悬浮搜索条，把应用、文件和日常工具放到一个入口。插件使用统一的声明式界面，适配主题与键盘操作。

## 开源项目

| 项目 | 内容 | 许可 |
| --- | --- | --- |
| [ZTools](https://github.com/ZToolsTeam/ZTools) | 桌面客户端与插件宿主 | GPL-3.0 |
| [ZTools Extensions](https://github.com/ZToolsTeam/ZTools-extensions) | 官方插件、SDK 与开发工具 | MIT |

## 参与共建

- [开发插件](https://github.com/ZToolsTeam/ZTools-extensions#5-分钟贡献你的首款插件)：从脚手架开始，为常用工作添加一个工具。
- [提交问题或建议](https://github.com/ZToolsTeam/ZTools/issues)：描述使用场景、系统版本与复现步骤。
