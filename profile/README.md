## English

Open the workspace dashboard or floating launcher bar with a single hotkey to unify apps, files, and daily utilities in one entry point. Plugins are built with a unified declarative UI that adapts to themes and keyboard-first navigation.

### Repositories

| Repository | Description | License |
| --- | --- | --- |
| [ZTools](https://github.com/ZToolsTeam/ZTools) | Desktop client and plugin host for Windows &amp; macOS | GPL-3.0 |
| [ZTools Extensions](https://github.com/ZToolsTeam/ZTools-extensions) | Official plugins, declarative UI SDK, and developer tools | MIT |

### Contributing

- [Build a Plugin](https://github.com/ZToolsTeam/ZTools-extensions/blob/main/CONTRIBUTING.md): scaffold and submit a declarative extension for everyday workflows.
- [Report Issues or Ideas](https://github.com/ZToolsTeam/ZTools/issues): share your use case, OS version, and reproduction steps.
- [Download Releases](https://github.com/ZToolsTeam/ZTools/releases): browse release notes and signed installers.

## 简体中文

通过快捷键打开工作台或悬浮搜索条，把应用、文件和日常工具放到一个入口。插件使用统一的声明式界面，适配明暗主题与全键盘操作。

### 开源项目

| 项目 | 内容 | 许可 |
| --- | --- | --- |
| [ZTools](https://github.com/ZToolsTeam/ZTools) | Windows 与 macOS 桌面客户端与插件宿主 | GPL-3.0 |
| [ZTools Extensions](https://github.com/ZToolsTeam/ZTools-extensions) | 官方插件、声明式 UI SDK 与开发工具 | MIT |

### 参与共建

- [开发插件](https://github.com/ZToolsTeam/ZTools-extensions/blob/main/CONTRIBUTING.md)：从脚手架开始，为常用工作添加一个工具。
- [提交问题或建议](https://github.com/ZToolsTeam/ZTools/issues)：描述使用场景、系统版本与复现步骤。
- [查看版本发布](https://github.com/ZToolsTeam/ZTools/releases)：获取发布说明与官方签名安装包。
